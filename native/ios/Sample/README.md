# iOS sample

1. Create a SwiftUI app in Xcode and add this package (File, Add Package Dependencies, Add Local, pick `native/ios`).
2. Register the URL scheme `customdomainsample` (Target, Info, URL Types).
3. Replace the generated `ContentView.swift` with the one here, and set your application id and token endpoint.
